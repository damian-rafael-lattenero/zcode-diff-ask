# Long-form Notes

These notes exist so the fixture has a markdown file with plenty of
prose paragraphs and inline formatting. The panel should be able to
highlight individual words inside **bold** spans, `code` spans and
regular text without any difference in behavior.

## Section One: alpha

The alpha section talks about selection. When a user paints the word
"alpha" on line eight and then scrolls away to paint three letters of
another word much further down, both painted fragments must stay
visible as amber stripes until the user clears them.

## Section Two: bravo

The bravo section talks about revert. A painted fragment can be
reverted surgically: only the characters inside the stripe go back to
their original text, and everything around them stays untouched. This
works for single words, for parts of words, and for whole lines.

## Section Three: charlie

The charlie section exists for spacing. It repeats a few sentences so
the file is long enough to require scrolling in a small panel window.
Scrolling must never destroy painted fragments. Persistence is the
whole point of the brush model.

## Section Four: delta

Delta adds bullet lists:

- first bullet with the word alpha inside
- second bullet with the word bravo inside
- third bullet with the word charlie inside

## Section Five: echo

Echo closes the notes with a small table:

End of notes.
